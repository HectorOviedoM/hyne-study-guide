# Study Guides

Personal English study site. The home page (`index.html`) is a book hub. Each book has its own contents page so chapter URLs stay stable.

**Books**

- [General / Intro](hyne.html) — notes on Norman J. Hyne, *Nontechnical Guide to Petroleum Geology, Exploration, Drilling & Production* (3rd ed.). Chapters: Introduction, 1, 9–11, 14–19, 21, 24. Those HTML files stay at the repo root (`intro.html`, `ch01.html`, `ch09.html`, …).
- [Well Logging in Nontechnical Language](logging.html) — notes from the well-logging course doc. Chapters 1–3 (`logging-ch01.html` … `logging-ch03.html`).

To add a book, append an object in `books.js` and add a book home page in the same style as `hyne.html` or `logging.html`. Do not special-case the new book inside an existing chapter.

Open `index.html` locally. Diagrams are study figures from the course docs. Not a substitute for the books.
