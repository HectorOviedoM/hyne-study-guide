A self-contained English rewrite of Hector’s study notes—petroleum systems through well testing—with original diagrams and WITSML / data-engineer callouts.

How to use

  1. Open any chapter card below (or use the header nav). Everything works offline—no CDN, no login.
  2. Use the search box to filter chapter cards on this hub, or headings on a chapter page.
  3. On chapter pages, the sticky TOC jumps to sections. End each chapter with Check yourself (answers hidden until you open them).
  4. Watch for teal Data engineer / WITSML boxes—they map geology terms to typical objects and columns.
  5. Print a chapter if you like: the print stylesheet hides navigation.
